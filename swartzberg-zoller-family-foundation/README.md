# Swartzberg Zoller Family Foundation Website

A complete, professional website for the Swartzberg Zoller Family Foundation, a registered 501(c)(3) nonprofit organization.

- **Website:** https://swartzberg-zoller-family-foundation.bond
- **Status:** 501(c)(3) Public Charity (Illinois, founded 2011)

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router DOM
- React Helmet Async
- Lucide React

## Installation

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment

The `dist` folder can be deployed to any static hosting service including GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## SEO Features

- Sitemap.xml
- robots.txt
- Schema.org Organization JSON-LD
- Canonical URLs on every page
- Unique meta descriptions per page
- 404.html fallback page
